# Muhammad Haris - Personal Portfolio

A modern, clean, and responsive portfolio website built with React, TypeScript, and Tailwind CSS.

## Features

- **Clean Sidebar Navigation** - Beautiful card-style navigation with smooth transitions
- **Single Page View** - No scrolling, each section fills the entire screen
- **Dark/Light Theme** - Toggle between themes with smooth transitions
- **Responsive Design** - Works perfectly on all devices
- **Smooth Animations** - Powered by Framer Motion
- **Featured AI Translation Project** - Showcasing real-time translation capabilities

## Tech Stack

- **Frontend**: React 18, TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: React Icons
- **Build Tool**: Vite

## Getting Started

1. **Install dependencies**
   ```bash
   npm install
   ```

2. **Start development server**
   ```bash
   npm run dev
   ```

3. **Build for production**
   ```bash
   npm run build
   ```
