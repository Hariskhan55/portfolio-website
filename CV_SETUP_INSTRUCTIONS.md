# CV Setup Instructions

## How to Add Your CV for Download

1. **Copy your CV file** from `C:/Users/Admin/Downloads/Harisresume.pdf`

2. **Rename it** to `Muhammad_Haris_Resume.pdf`

3. **Place it** in the `public` folder of your project:
   ```
   personal-portfolio/
   ├── public/
   │   ├── Muhammad_Haris_Resume.pdf  ← Place your CV here
   │   └── vite.svg
   ├── src/
   └── ...
   ```

4. **Replace the placeholder file** that's currently in the public folder

## Why This Setup?

- Files in the `public` folder are served directly by the web server
- This allows users to download your CV when they click the "Download CV" button
- The file will be accessible at `/Muhammad_Haris_Resume.pdf` when your site is deployed
